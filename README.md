# E-FORECAST

## Summary

E-FORECAST is a household electricity consumption and bill forecasting system. It aims to help households monitor their electricity usage, record their consumption history, and estimate their future electricity consumption and bills.

The initial version includes a Home screen and a Login screen as the starting point for future features.

## Current Stack

- Frontend: Flutter Web and Dart
- Planned Backend:REST API using FastAPI with Python
- Planned Database: PostgreSQL
- Version Control: Git and GitHub
- Browser: Google Chrome

Note: The REST API and PostgreSQL integration are planned components and have not yet been implemented in Activity 8.

## Project Structure

- `lib/main.dart` — Application entry point
- `lib/app.dart` — Application configuration and navigation
- `lib/screens/` — Home and Login screens
- `lib/widgets/` — Reusable buttons and text fields
- `lib/services/` — Planned API and service integration
- `lib/models/` — Planned data models
- `lib/routes/` — Routing organization
- `lib/constants/` — Shared application constants

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/jelyntac-an-crypto/tac_an_project-.git
```

### 2. Open the project directory

```bash
cd tac_an_project
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the Flutter Web application

```bash
flutter run -d chrome
```
